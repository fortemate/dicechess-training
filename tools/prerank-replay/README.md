# Complete-turn replay audit

This diagnostic consumes a `playground-prerank-groups-v1` JSON array. It re-enumerates legal
complete turns with the pinned engine, matches stored move paths, calls `endTurn`, and compares
rich-9 features from the **root mover** perspective. It checks terminal sentinels but cannot
verify private nonterminal teacher targets. Run the private teacher separately at its pinned revision.

```sh
sbt -batch test
sbt -batch 'run <groups.json> <report.json> <states.jsonl>'
```

Run the ordinary Python dataset admission first to verify schema, digests and provenance.
This is an additional replay diagnostic, not a replacement admission API. A successful exit means
that the audit completed; inspect the report before accepting data. This tool does not train,
repair, upload, or change serving contracts.

`report.json` counts illegal/incomplete paths, missing/extra normalized states, feature/result
mismatches, terminal-target mismatches, and normalized keys merging distinct complete EP states.
It compares rich-9 plus both exact KCP calls across each EP collision; identical signatures do
not establish equality for a different evaluator, nor equivalence of legal successor turns.
Full DFEN witnesses preserve clocks. The overlap fingerprints retain placement, active color,
castling and **all EP targets**, excluding clocks (unused by these pinned feature contracts).

`states.jsonl` contains a record per group with source-game identity, root fingerprint and
fingerprints of the stored candidates reconstructed from paths. Use these to audit cross-split
state overlap and count exact-unseen **whole groups**. They describe retained candidates; they
cannot recover alternatives the producer already dropped or prove original source-root fidelity.

Treat both outputs as private when the input is private: reports contain example positions and
paths, while fingerprints and source-game IDs are still derived corpus data. Keep output paths
outside public repository trees. No corpus or teacher configuration belongs in this directory.

The synthetic suite covers delayed en-passant, complete-turn legality, both root colors,
terminal missing kings, and corrupted features/terminal labels. It uses engine 0.12.0 to audit
corpora generated by that artifact; a new engine requires a separately versioned replay.
