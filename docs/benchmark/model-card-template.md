# Position evaluator qualification card

Complete and retain this card in the owner's private audit store. Do not commit filled experiment
verdicts, model identities, data locations or production settings to the public repository.

| Field | Required evidence |
| --- | --- |
| Intended use | ADR 0001 position/leaf evaluator; feature schema and side-to-move probability |
| Target limitation | Binary outcomes conditional on decisive games; draw exclusion acknowledged |
| Benchmark | Protocol commit, canonical protocol digest and implementation digest |
| Data | Development/final schema, version and canonical manifest digests; reviewed source/rights evidence |
| Custody | Immutable preregistration record, custodian and single final-attempt audit record |
| Training | Manifest, source/config/data/group digests, enrichment engine and seed |
| Comparator | Complete accepted reference inventory and predeclared promotion comparator |
| Offline report | Report digest; all/unseen metrics, confidence intervals, slices and overlap counts |
| Probes | Serving suite digest and exact candidate-bound raw evidence digest |
| Serving | Torch/ONNX/JVM parity; terminal and piece-safety assertions; preregistered envelope checks |
| Limitations | Unsupported slices, teacher/ranking limitations, known data selection bias |
| Decision | Owner review of every failed gate; qualification is separate from any deployment decision |
